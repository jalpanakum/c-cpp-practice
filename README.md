# C/C++ Practice

This repository contains my practice programs while learning and preparing for C/C++ programming interviews.

## 📚 Topics Covered

### C Programming

* Basic syntax and input/output
* Variables and data types
* Conditional statements
* Loops
* Functions
* Arrays
* Strings
* Pointers
* Structures
* Dynamic memory allocation
* File handling

### C++ Programming

* Classes and objects
* Constructors and destructors
* Inheritance
* Polymorphism
* Encapsulation
* STL
* Templates

### Advanced Topics

* Data structures
* Multithreading
* Linux programming
* Socket programming
